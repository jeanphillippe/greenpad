Plugins disponibles

Instalá los que quieras. Después se prenden, apagan o quitan desde el menú de GREENPAD, en Plugins.

Cómo se usan

  1. Instalá el plugin desde esta página. Queda guardado en este equipo y sigue andando sin conexión.
  2. Volvé a GREENPAD. Los instrumentos aparecen al mantener apretado el ícono de cada uno, las perillas y botones en las bandejas, y los visuales en Descargar, en el estilo del video.
  3. Administralos desde el menú, en Plugins: ahí se prenden, se apagan o se quitan.

Hacé tu plugin

Un plugin es un solo archivo .js. No hace falta instalar nada: se escribe en cualquier editor de texto y se prueba en el navegador. Los de la lista de arriba sirven de ejemplo: cada uno tiene su enlace Ver código.

Bajar la plantilla

1. La forma del archivo

Todo va dentro de una llamada a GREENPAD.plugin. Los datos de arriba son los que se muestran en esta página y en el menú. En setup se registra lo que el plugin suma, usando el objeto gp.

GREENPAD.plugin({
  id: 'mi-plugin',          // en minúsculas, sin espacios. No se cambia más
  nombre: 'Mi plugin',
  autor: 'Tu nombre',
  version: '1.0',
  tipo: 'sonido',           // sonido, bandeja o visual
  descripcion: 'Qué hace, en una línea.',

  setup(gp) {
    // acá van gp.instrumento, gp.efecto, gp.boton, gp.estilo y gp.visual
  },
});

Un mismo plugin puede sumar varias cosas (por ejemplo, tres instrumentos y una perilla).

2. Un instrumento Sonido

gp.instrumento(pista, datos) suma un estilo a uno de los 8 instrumentos. Las pistas son 'BD' bombo, 'SN' caja, 'HH' hi-hat, 'PC' percu, 'BS' bajo, 'GT' guitarra, 'CH' acordes y 'LD' melodía.

gp.instrumento('LD', {
  id: 'campana',
  nombre: 'Campana',
  detalle: 'Corta y brillante',
  tocar(ctx, salida, t, fuerza, nota, afin, info) {
    const osc = ctx.createOscillator(), vol = ctx.createGain();
    osc.type = 'triangle';
    osc.frequency.value = nota.f;                 // la nota que toca, en Hz
    vol.gain.setValueAtTime(.4 * fuerza, t);
    vol.gain.exponentialRampToValueAtTime(.001, t + .5);
    osc.connect(vol); vol.connect(salida);
    osc.start(t); osc.stop(t + .55);
  },
});
DatoQué es
ctxEl AudioContext (Web Audio). En Descargar es uno sin conexión: el mismo código arma el archivo.
salidaAdonde se conecta el sonido. Nunca a ctx.destination.
tEl momento exacto en que tiene que sonar. Todo se programa con t, sin setTimeout.
fuerzaDe 0 a 1 (más con el destiempo prendido). Qué tan fuerte es el golpe.
notaEn bajo, guitarra, acordes y melodía: { f, fs, dur }, la frecuencia, las frecuencias del acorde (en guitarra y acordes) y la duración en segundos. En la batería viene vacía (null).
afinLa afinación que eligió quien toca (1 es normal). En las notas ya viene aplicada; en la batería, multiplicá tus frecuencias por este número.
infoUn séptimo dato, opcional: { bpm, paso }, el tempo y cuánto dura un paso en segundos. Sirve para redobles y ecos a tiempo (con enVivo: true en la batería).

En caja, hi-hat y percu el sonido se arma una vez y después se repite, para que el teléfono no se trabe. Si el tuyo tiene que armarse en cada golpe, agregá enVivo: true.

Con las grabaciones de GREENPAD. Un plugin puede usar los instrumentos grabados que ya trae la app (guitarras, bajo, piano, batería, percusión) y pasarlos por sus propios efectos. Se avisa cuáles con usa, así se bajan antes de sonar:

gp.instrumento('GT', {
  id: 'octavada', nombre: 'Octavada', detalle: 'Eléctrica con su octava',
  usa: ['gt_electrica'],
  tocar(ctx, salida, t, fuerza, nota) {
    gp.nota(ctx, salida, t, fuerza, 'gt_electrica', nota.f, nota.dur, { volumen: .4 });
    gp.nota(ctx, salida, t, fuerza, 'gt_electrica', nota.f * 2, nota.dur, { volumen: .25 });
  },
});
FunciónQué hace
gp.nota(ctx, salida, t, fuerza, clave, f, dur, op)Toca la grabación afinada a f. En op: volumen, cola (cuánto sigue sonando), max, brillo, desafinar. Devuelve false si todavía no llegó.
gp.golpe(ctx, salida, t, fuerza, clave, op)Un golpe de batería o percusión. En op: volumen y velocidad (más de 1 lo sube de tono).
gp.grabado(clave, f)Devuelve { buffer, velocidad } para armar el sonido a mano (por ejemplo, para un vibrato).
gp.distorsion(ctx, cuanto)Un nodo de distorsión, de 1 (apenas) a 60 (muchísimo).
gp.grabacionesLa lista de claves: gt_electrica, gt_acustica, gt_criolla, gt_muteada, bs_electrico, ch_piano, pc_conga, pc_palmas, bd_banda y las demás.

Un ejemplo para el menú. gp.ejemplo suma un ritmo armado a Ejemplos, con los estilos del plugin ya elegidos. Va después de los instrumentos:

gp.ejemplo({
  nombre: 'Mi ritmo', detalle: 'Qué tiene', bpm: 120,
  notaBase: 'Mi',                 // Do, Re, Mi, Fa, Sol, La, Si
  ambiente: 'Oscuro',             // Oscuro, Triste, Alegre, Pop, Groove, Blues
  estilos: { GT: 'Octavada', BS: 'Eléctrico' },
  ritmo: { BD: 'x.......x.......', SN: '....x.......x...', GT: '1...3...5...3...' },
});

Para usar grabaciones propias: const s = gp.sonido('plugins/mi-plugin/golpe.mp3') en setup, y en tocar, gp.tocarSonido(ctx, salida, t, fuerza, s, { velocidad: afin }). Los archivos de audio se mandan junto con el .js.

3. Mods para las bandejas Bandejas

Una perilla de efecto. Toda la mezcla pasa por el efecto. Con la perilla en 0 queda desenchufado.

gp.efecto({
  id: 'filtro',
  nombre: 'Filtro',                               // hasta 10 letras
  crear(ctx) {
    const f = ctx.createBiquadFilter();
    f.type = 'lowpass';
    return {
      entrada: f,
      salida: f,
      ajustar(valor, info) {                      // valor: de 0 a 1. info.bpm: el tempo
        f.frequency.value = 18000 * Math.pow(.02, valor);
      },
    };
  },
});

info trae bpm, ahora (la hora del audio) e inicio (cuándo cayó el primer paso del compás, o vacío si la música está quieta), para los efectos que van a tiempo.

Un botón que dispara un sonido. soltar es opcional y sirve para los que suenan mientras se mantienen apretados.

gp.boton({
  id: 'bip',
  nombre: 'Bip',
  detalle: 'Un tono corto',
  tocar(ctx, salida, t) { /* armar el sonido y conectarlo a salida */ },
  soltar(ctx, t) { /* apagarlo */ },
});

Un botón también puede llevar color y fijo: true (queda prendido hasta tocarlo de nuevo). Si tocar devuelve false, o una promesa que da false, el botón se apaga.

El micrófono. gp.microfono() devuelve una promesa con un nodo de audio (el navegador pide permiso la primera vez). Se conecta a los efectos que quieras y a salida. Al terminar, gp.soltarMicrofono(ms) lo apaga pasado ese tiempo.

Otra pinta. gp.estilo(css) agrega CSS a la página. Las bandejas están dentro de #dj: el disco es .disc, la etiqueta .lab, el brazo .arm y la consola del medio .mxr.

gp.estilo('#dj .disc{filter:hue-rotate(120deg)}');

4. Un visual para el video Visuales

dibujar se llama 30 veces por segundo sobre un canvas de 720 × 1280. g es su contexto 2D y v trae lo que pasa en la música en ese cuadro.

gp.visual({
  id: 'pulso',
  nombre: 'Pulso',
  detalle: 'Un círculo que late con el bombo.',
  dibujar(g, v) {
    g.fillStyle = '#060b08'; g.fillRect(0, 0, v.W, v.H);
    g.fillStyle = v.color;
    g.beginPath();
    g.arc(v.W / 2, v.H / 2, 120 + v.bombo * 80, 0, Math.PI * 2);
    g.fill();
  },
});
En vQué trae
W, HEl tamaño: 720 y 1280.
ahora, durSegundos desde que empezó el tema y cuánto dura.
pulsosEl tiempo contado en negras. Sirve para que todo se mueva con el tempo.
bombo, cajaDe 0 a 1: saltan a 1 con cada golpe y se apagan solos.
graves, mediosDe 0 a 1: cuánto suena cada zona.
niveles8 valores, uno por instrumento (en el orden de las pistas): 1 cuando suena, y se va apagando.
bandas(n)Devuelve n valores de 0 a 1, de graves a agudos (de 2 a 64).
frecuencias, ondaLos datos crudos del sonido (de 0 a 255), por si hacen falta.
color, color2, coloresLos colores de la parte que suena y la paleta de GREENPAD.
paso, trackEl paso (0 a 15) y la letra del track que suena.
titulo, bpmEl nombre del tema y el tempo.
memoriaUn objeto vacío que se conserva de un cuadro al otro, para guardar partículas, posiciones o lo que haga falta.

El logo de GREENPAD se dibuja solo, abajo. Con logo: false no aparece.

5. Otras ayudas de gp

FunciónPara qué
gp.cuando('paso', fn)Avisa en cada paso que suena: fn({ paso, track }). También hay 'play' y 'stop'.
gp.ruido()Un segundo de ruido blanco, para platillos, soplidos y golpes.
gp.sonido(url)Carga un archivo de audio. Se usa con gp.tocarSonido.
gp.tocar(pista, nota)Toca un instrumento de GREENPAD, con el estilo que tenga elegido.
gp.aviso(texto)Muestra un cartel corto abajo.
gp.estado()Tempo, si está sonando, track y nombre del tema. Se usa después de setup, no adentro.

6. Probarlo

  • Abrí GREENPAD, menú, Plugins, Probar un plugin propio (.js) y elegí tu archivo. La página se recarga con el plugin puesto.
  • Cada vez que cambies el archivo, cargalo de nuevo: reemplaza al anterior.
  • Si algo falla, el menú muestra el error al lado del plugin. Si la página queda rota, abrila con ?sinplugins al final de la dirección y quitalo.
  • Probá también Descargar (audio y video): tiene que sonar igual que en vivo.

7. Para que entre en la lista

  • Un solo archivo .js, más los audios si usa grabaciones propias o con licencia libre.
  • Tiene que andar sin conexión: nada de pedir cosas a otros sitios.
  • No lee ni guarda datos de quien lo usa.
  • Código legible, sin comprimir, para poder revisarlo antes de publicarlo.
