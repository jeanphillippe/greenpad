    Esta ayuda ?

    Patrones A a H: son 8 memorias, cada una con su propia grilla de 16 pasos (por ejemplo A intro, B estrofa, C estribillo). Si cambiás de patrón mientras suena, entra al terminar el compás; tocalo otra vez para saltar ya. Con CADENA encendido suenan uno detrás de otro, salteando los vacíos.

    Instrumentos: tocá un ícono para escucharlo. Mantenelo apretado (o clic derecho) para elegir su estilo, afinación y volumen, o para silenciarlo.

    En el teléfono, tocá y arrastrá sobre la grilla para pintar varios pasos. También podés soltar un .txt sobre la página para importarlo.
